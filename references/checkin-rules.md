## 2. 签到与连签节点

每天在活动页点一次签到，当天未签不可补、不顺延。

| 连签节点 | 奖励 | 说明 |
| --- | --- | --- |
| 第 3 天 | 网盘 SVIP 天卡 | 首个节点，页面文案形如「已签2天，再签1天领网盘会员天卡」 |
| 第 7 天 | 网盘 SVIP 卡 | 档位以页面公示为准 |
| 第 15 天 | 网盘 SVIP 卡 | 档位以页面公示为准 |
| 第 30 天 | **网盘 SVIP 月卡（必得）** | 本期终极奖励，达标即发，不是抽奖 |

- 每日签到发 **库库积分+10、抽奖+1**（活动页日历每格都标着「+10」「抽奖+1」，实测；旧期是 50）。
- **断签清零**：连续天数回到第 1 天，已解锁的节点进度失效；**已经发到手的 SVIP 不回收**。
- 页面会显示「距离活动结束 XX天XX:XX:XX」倒计时，脚本会读出来。

按钮状态（图片名）映射：

| 图片 | 含义 | 脚本动作 |
| --- | --- | --- |
| `btn_todo.png` | 未完成 | 点 `.pc-kuku-task-card__action` |
| `btn_done.png` | 已完成 | 跳过，记为完成 |
| `btn_invite.png` | 需邀请好友 | 跳过（需真人） |

- 实测账号只有 5 张卡；部分账号多一张「下载并登录库库PC客户端」（`btn_todo`），需装客户端，脚本不处理。
- 本期**没有**「上传一次本地文件」「导入一次网盘文件」任务——第三方攻略写的这两项在真实任务中心不存在。
- 任务卡顺序会变，脚本按标题匹配而不是按顺序。
- 完成一项会弹「任务完成，获得抽奖次数+1」toast，可作为成功信号。
- 进度显示在标题里，形如 `与库库聊聊热门话题(1/3)`，脚本据此算剩余次数。
- **补签**：日历历史日期有「补」按钮，「点击可补签对应天数」，脚本不自动补签。
- **专家协议**：点「召唤」会弹《库库 AI 用户协议》，需勾「我已阅读并同意」→「继续使用」，否则不出现输入框。

## 4. 页面结构（实测 + data-testid）

签到卡在主页面，真正的活动内容在 **iframe** 里，两层都要处理。

### 4.1 主页面（工作台左下角）

| 元素 | 选择器 | 说明 |
| --- | --- | --- |
| 签到卡 | `[data-testid="signin-promo"]` | 240×214，可关闭 |
| 标题 | `[data-testid="signin-promo-title"]` | 未登录「登录领取网盘SVIP」；**点它会打开任务中心** |
| 副标题 | `[data-testid="signin-promo-subtitle"]` | 「每日签到 必得网盘会员月卡」 |
| CTA | `[data-testid="signin-promo-cta"]` | 未登录「登录领奖」 |
| 日格 | `.signin-promo-day` | 每格「积分+10」+ 日期 |
| 活动横幅 | `button.activity-banner` | 图片按钮，`innerText` 为空 |
| 活动弹窗关闭 | `[data-testid="activity-dialog-close"]` | 弹窗下方圆形 ✕，**不关会拦掉点击** |
| 任务中心 iframe | `iframe.signin-center-iframe` | 内容层 |

### 4.2 iframe 内（`/operation/activitys/kukuPcSignAct/main`）

| 元素 | 选择器 | 说明 |
| --- | --- | --- |
| 签到按钮 | `button.pc-sign-btn` | 未登录「登录领奖」，签到后文案变化（脚本据此判状态） |
| 全部日历 | `button.pc-sign-cal__all-btn` | 「查看全部日历」 |
| 日历容器 | `.pc-sign-cal__grid` | 每天一格，标「+10 / 抽奖+1」 |
| 任务卡 | `.pc-kuku-task-card` | 6 张 |
| 任务标题 | `.pc-kuku-task-card__title` | 纯文本，可读 |
| 任务按钮 | `.pc-kuku-task-card__btn` | **是 `<img>`，没有文字**，靠文件名判状态 |
| 按钮容器 | `.pc-kuku-task-card__action` | 点击目标 |

### 4.3 三个必须知道的坑

1. **iframe 不能直接访问**：`https://kuku.baidu.com/operation/activitys/kukuPcSignAct/main` 单独打开 body 为空（依赖父页面上下文）。必须先从工作台点签到卡标题把弹窗打开。
2. **「去完成」不是文字**：它是 `btn_todo.png` 图片，任何按文案点击的写法都会失败。必须定位卡片 → 读图名 → 点 `.pc-kuku-task-card__action`。
3. **会员弹窗遮罩**：页面加载弹一次、打开任务中心又弹一次，真实鼠标点击会被吃掉（Playwright 报 `locator resolved ... but click timed out`）。先点 `activity-dialog-close`，仍失败就退化为 `element.click()` DOM 点击。

### 4.4 流程

1. 打开官网 → 关会员弹窗 → 判登录态。
2. 点 `[data-testid="signin-promo-title"]` → 等 `iframe.signin-center-iframe` 出现。
3. 读 `button.pc-sign-btn` 文案：含「已签/明日再来」= 今日已完成；含「签到/领奖」= 未签。
4. 未签则点它 → 再读文案复核。
5. 逐张任务卡：`btn_todo` → 点 `__action`；`btn_invite` → 跳过（需真人）。
6. 每清一项任务前重新确认 iframe 还在（点「去完成」会跳到对话页，弹窗可能被关）。


## 5. 常见问题

| 问题 | 说明与处理 |
| --- | --- |
| 提示「未找到 Cookie 文件」 | 用户还没提供 Cookie。提示导出（见 cloud-mode.md）或粘贴后落盘。 |
| 提示「登录态失效」 | Cookie 过期，重新导出。 |
| 任务中心打不开 | `--dry-run --probe-entry` 看截图；签到会走签到卡 CTA 兜底，任务跳过并记入 warnings。注意 iframe 地址不能直接打开。 |
| 找不到「立即签到」 | 页面改版。改 `assets/activity.json` 的 `signin_texts` 后 dry-run 复验。 |
| 出现验证码 / 滑块 | 立即停止，交回用户手动，不要绕过。 |
| 积分没变化 | 任务需「领取」后入账，或存在延迟；以页面任务状态为准并截图留证。 |
| 提示「今日已签」 | 今天已完成，正常，报告连签天数即可。 |
| 连签天数归零 | 昨天断了。如实告知已清零，从今天重新累计。 |
| 活动只剩几天 | `warnings` 会提示；提醒用户尽早连签，别卡最后几天。 |
