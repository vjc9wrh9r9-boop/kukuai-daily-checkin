库库AI 签到 + 每日任务 v3.4.0

用你自己的 Cookie，在无头浏览器里完成：签到、聊 3 条热门话题、逛 10 秒知识广场。
默认不做「召唤专家」（会弹用户协议，需本人同意后加 --with-expert）和邀请类任务（必须真人）。

一、装到哪
  解压后把 kukuai-checkin-tasks 文件夹放到：
    Windows:  C:\Users\<用户名>\.workbuddy\skills\
    macOS:    ~/.workbuddy/skills/
  路径只用英文数字，中文目录可能触发某些 Agent 的技能路径保护。

二、拿到 Cookie（两个按钮，最省事）
  双击 tools\GetCookie.exe（也可以让 Agent 直接帮你打开）
    打开后是一个小窗口，不会自己开网页，只有两个按钮：

    ① 打开网页登录库库AI，抓取 Cookie
       → 用你系统的默认浏览器弹一个窗口（独立临时配置，不动日常浏览器数据）
       → 浏览器会停在工作台 https://www.kukuai.cn/（邀请页另开一个标签，不用管）
       → 登录入口：点工作台左下角签到卡上的「登录领奖」（或右上角头像），
         用百度账号扫码或密码登录
       → 登录成功后会调用工作台接口复核，确认已登录才保存，状态条变绿：「抓取成功（工作台已确认登录）」
       → 复核没过会变红并说明原因（如「工作台接口一直返回未登录，登录可能没真正完成」）
       → 判断登录成功的标志：网页右上角出现头像、签到卡不再显示「登录领奖」

    ② 复制已抓取的 Cookie
       → 点一下就复制到剪贴板，状态条显示「已复制 N 条，去 Agent 对话里 Ctrl+V」
       → 然后到 Agent 对话里粘贴发送即可

    Cookie 同时存到 C:\Users\<用户名>\.kukuai\cookies.json（脚本默认读这里）。
    首次运行可能被 SmartScreen 拦：点「更多信息」→「仍要运行」。
    工具只读取它自己那个临时浏览器窗口的 Cookie，不碰你日常浏览器的数据，不上传任何东西。

  没有 exe 或想手工做：
    1. 浏览器登录 https://kuku.baidu.com/home（或 https://www.kukuai.cn/）
    2. F12 → Application → Cookies → 对应的域
    3. 复制 BDUSS 的值（HttpOnly，只能在这里复制；有 STOKEN 就一起复制）
    4. 存成 C:\Users\<用户名>\.kukuai\cookies.json：
         {"BDUSS":"你的值","STOKEN":"你的值"}

  Cookie 等同账号密码，只存本机，别发给任何人。

三、运行
  pip install playwright
  python -m playwright install chromium

  # 1) 先探测，不签到不点任务
  python scripts/kukuai_checkin.py --cookies ~/.kukuai/cookies.json --dry-run --probe-entry
  # 2) 正式跑
  python scripts/kukuai_checkin.py --cookies ~/.kukuai/cookies.json
  # 3) 只签到
  python scripts/kukuai_checkin.py --cookies ~/.kukuai/cookies.json --only-signin
  # 4) 连专家任务也做（会代勾用户协议，本人确认后用）
  python scripts/kukuai_checkin.py --cookies ~/.kukuai/cookies.json --with-expert

四、它到底动了什么
  动的：签到按钮、热门话题对话（3 条行业问题）、知识广场停留 12 秒。
  不动的：不发邀请、不上传文件、不分享、不抽奖、不改设置；Cookie 不写日志、不回传。

五、输出
  outputs/kukuai-summary-<时间>.md   一句话人类可读汇总
  outputs/kukuai-*.png               各阶段全页截图
  outputs/log/                       逐步日志
  stdout                             一段 JSON（ok / signed_today / streak_days / tasks / warnings）

六、想每天自动跑：两种方式，别搞混
  (A) Agent 自带的定时任务 / 自动化任务
      在 Agent 界面里新建一条每天固定时间的周期任务，由 Agent 客户端触发，
      跑完会按对话把结果汇报给你。
      ⚠️ 这不是 Windows 计划任务（taskschd.msc）、不是 crontab、不是开机启动项。
         别用 schtasks / crontab 配，配了不归 Agent 管，结果也没人汇报。
      缺点：客户端没开的那天不会跑。

  (B) GitHub Actions（纯云端，电脑关机也跑）
      只签到版模板：https://github.com/vjc9wrh9r9-boop/kukuai-signin-template
      完整版示例见 references/cloud-mode.md 第 6.2 节。
      结果在仓库的 issue / Actions Summary 里看。

  对照：
      方式                    | 谁触发      | 结果推给你 | 关机也跑
      Agent 定时任务          | Agent 客户端 | 能        | 不能
      Windows 计划任务/crontab | 操作系统     | 不能      | 不能
      GitHub Actions          | GitHub 云端  | 能        | 能

七、常见问题
  报「登录态失效」→ Cookie 过期，重新导出
  报「页面多次重载仍未渲染」→ 网络不通，换网络或重试
  报「没打开任务中心」→ 页面改版，看截图，按 SKILL.md 的选择器表更新
  出现验证码 → 脚本已停，需人工登录完成
