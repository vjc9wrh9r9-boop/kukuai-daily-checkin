一、装到哪
  解压后把 kukuai-checkin-tasks 文件夹放到：
    Windows:  C:\Users\<用户名>\.workbuddy\skills\
    macOS:    ~/.workbuddy/skills/
  路径只用英文数字，中文目录可能触发某些 Agent 的技能路径保护。

二、拿到 Cookie（双击工具，两步搞定）
  这个文件夹里除了技能目录，还有一个 GetCookie-v3.8.3.exe，双击就能用（不用装、不用登录）。

    1) 解压收到的压缩包，找到 GetCookie-v3.8.3.exe，双击打开
    2) 点蓝色按钮「① 打开网页登录库库AI，抓取 Cookie」
       → 会用你系统默认浏览器弹一个窗口（独立临时配置，不动日常浏览器数据）
       → 在网页里点左下角签到卡上的「登录领奖」，用百度账号扫码或密码登录
       → 登录成功后工具会自动抓取，状态条变绿并标注「登录域」
    3) 点「② 复制已抓取的 Cookie」→ 回到对话里 Ctrl+V 粘贴给 AI

  说明：
    · 抓到 2 条或 14 条都正常（2 条=登录在 kuku.baidu.com，14 条=登录在 www.kukuai.cn，
      同一账号、同一份进度，脚本会自动选对入口）
    · 工具是自制小工具（不是百度官方），源码在 tools/get_cookie.py，不装扩展、不上传数据
    · Cookie 存在 C:\Users\<用户名>\.kukuai\cookies.json
    · 首次运行被 SmartScreen 拦：点「更多信息」→「仍要运行」

四、它到底动了什么
  动的：签到按钮、热门话题对话（3 条行业问题）、知识广场停留 12 秒。
  不动的：不发邀请、不上传文件、不分享、不抽奖、不改设置；Cookie 不写日志、不回传。

六、想每天自动跑：两种方式，别搞混
  (A) Agent 自带的定时任务 / 自动化任务
      在 Agent 界面里新建一条每天固定时间的周期任务，由 Agent 客户端触发，
      跑完会按对话把结果汇报给你。
      ⚠️ 这不是 Windows 计划任务（taskschd.msc）、不是 crontab、不是开机启动项。
         别用 schtasks / crontab 配，配了不归 Agent 管，结果也没人汇报。
      缺点：客户端没开的那天不会跑。

  (B) GitHub Actions（纯云端，电脑关机也跑）
      只签到版模板：https://github.com/vjc9wrh9r9-boop/kukuai-signin-template
      完整版示例见 references/cloud-mode.md 第 6.2 节。
      结果在仓库的 issue / Actions Summary 里看。

  对照：
      方式                    | 谁触发      | 结果推给你 | 关机也跑
      Agent 定时任务          | Agent 客户端 | 能        | 不能
      Windows 计划任务/crontab | 操作系统     | 不能      | 不能
      GitHub Actions          | GitHub 云端  | 能        | 能

七、常见问题
  报「登录态失效」→ Cookie 过期，重新导出
  报「页面多次重载仍未渲染」→ 网络不通，换网络或重试
  报「没打开任务中心」→ 页面改版，看截图，按 SKILL.md 的选择器表更新
  出现验证码 → 脚本已停，需人工登录完成
